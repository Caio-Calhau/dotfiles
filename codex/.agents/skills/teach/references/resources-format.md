# Resources format

Create `RESOURCES.md`:

```md
# {Topic} Resources

## Knowledge

- [Descriptive title](https://example.com)
  What it covers and when to use it.

## Wisdom (Communities)

- [Community](https://example.com)
  What feedback or practical knowledge it offers.

## Gaps

- {Knowledge the mission needs but no trustworthy resource yet covers}
```

Prefer primary sources, recognized experts, peer-reviewed work, and well-moderated communities. Annotate every entry. Remove sources that prove shallow, incorrect, or irrelevant. Record when the user does not want community recommendations.
