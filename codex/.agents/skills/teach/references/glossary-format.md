# Glossary format

Create `GLOSSARY.md`:

```md
# {Topic} Glossary

## Terms

**{Canonical term}**:
{One- or two-sentence definition.}
_Avoid_: {ambiguous aliases}
```

Add a term only after the user demonstrates understanding. Choose canonical language, keep definitions tight, reuse established glossary terms, group natural clusters, resolve ambiguity explicitly, and revise definitions as understanding deepens.
