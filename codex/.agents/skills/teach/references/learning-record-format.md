# Learning record format

Store records in `learning-records/` as sequential `0001-slug.md` files:

```md
# {What was learned or established}

{What the user demonstrated and why it changes future teaching.}
```

Optionally add evidence, implications, or `Status: superseded by LR-NNNN`.

Write a record only for demonstrated non-trivial understanding, meaningful prior knowledge, a corrected misconception, or a mission shift. Do not record material merely covered, glossary definitions, or session-by-session activity.
